# Code of Conduct

## Our standard

Open Agentic Brain and Memory is a small open-source project. The standard is simple: be respectful, be
constructive, and don't make this space unpleasant for anyone else in it.

In practice:

- Give feedback on the tool and the problems you hit, not on people.
- Assume good faith. Bug reports and blunt criticism of the *software* are welcome.
- No harassment, insults, discriminatory language, or personal attacks, in issues, pull
  requests, discussions, or any other communication related to this project.
- Respect that other users' data — their private repo, their `age` key, their captured
  memory — is theirs. Don't probe, access, or discuss another user's data without their
  explicit permission.

## Scope

This applies to every space connected to this project: GitHub issues, pull requests and
discussions, direct communication with the maintainers, and anywhere else this project is
discussed in a context tied back to it.

## Enforcement

Maintainers may edit or remove content, lock threads, or block contributors whose behavior
violates this standard. There is no formal committee or appeals process at this scale; if you
believe an enforcement decision was made in error, say so to the maintainers through the
contact below.

## Reporting

If something happens that concerns you, report it privately. Preferred: GitHub private
reporting on this repository's **Security** tab (**"Report a vulnerability"**; it reaches only
the maintainers, so it works for conduct reports too). If you can't use that, email
**agenticbrain@zohomail.in**. Reports are handled as discreetly as the situation allows.
